# Exploratory notebook — reference only

`australia_vietnam_trade_analysis.ipynb` computes RCA, EXPY and bilateral trade complementarity
for Australia and Vietnam.

**Its input data is hand-entered placeholder values, not sourced statistics.** The `AUS_exports`,
`VNM_exports`, `WORLD_exports` and `PRODY` dictionaries are rounded illustrative numbers written
directly into the notebook. They were never pulled from UN Comtrade, the ABS or any other
statistical source.

**Do not cite any figure produced by this notebook.**

The grounded equivalents are on the website, computed from published DFAT line items:

| Notebook (synthetic) | Website (sourced) |
|---|---|
| RCA by HS sector | Top-six concentration ratio (CR6) per direction — 71.4% vs 53.3% |
| EXPY sophistication index | Upstream / service / downstream value-chain split of each direction |
| Bilateral complementarity score | The actual 2025 line items in each direction, with shares |

The notebook is retained because the *analytical framing* — that Australia and Vietnam are
complementary rather than competing, and that Vietnam sits further downstream — carried through to
the final analysis. Only the numbers were replaced.
